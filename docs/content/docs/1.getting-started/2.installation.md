## Quick Start

Nuxt Scripts 2 requires Nuxt `^4.6.0 || ^5.0.0` and Unhead `^3.4.2`.
The supported Node.js range is `^22.22.3 || ^24.15.0 || >=26.0.0`.
Upgrade an existing project before installing:

```bash
npx nuxi@latest upgrade --force
```

Nuxt Scripts 2 is available on the `beta` channel. Run:

```bash
pnpm exec nuxt module add @nuxt/scripts@beta
```

> [!TIP]
> Using an AI agent? Get the @nuxt/scripts Skill on [skilld.dev/gh/nuxt/scripts/nuxt-scripts](https://skilld.dev/gh/nuxt/scripts/nuxt-scripts).

The [Nuxt module command](https://nuxt.com/docs/api/commands/module) installs Nuxt Scripts and adds it to the `modules` array in your Nuxt config.

The DevTools panel uses the optional `@nuxt/scripts-devtools` package.
Install the same version as `@nuxt/scripts`, then restart Nuxt:

```bash
pnpm add -D @nuxt/scripts-devtools@beta
```
